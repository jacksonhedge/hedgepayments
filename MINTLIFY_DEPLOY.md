## 🚀 Deploy in 3 Steps (2 minutes)

### Step 1: Sign Up for Mintlify Cloud

1. Go to **https://mintlify.com**
2. Click "Get Started" or "Sign Up"
3. **Sign in with GitHub** (recommended)

### Step 2: Import Your Repository

1. After signing in, you'll see "New Project" or "Import Repository"
2. Select your repository: **`jacksonhedge/hedgepayments`**
3. Configure the import:
   ```
   Root Directory: /docs
   Branch: main
   ```
4. Click "Import"

### Step 3: Deploy!

Mintlify will automatically:
- ✅ Detect your `mint.json` configuration
- ✅ Build your documentation
- ✅ Deploy to a live URL: `hedgepayments.mintlify.app`

**That's it! Your docs are live in ~30 seconds.**

## 🌐 Custom Domain (Optional)

### Add `docs.hedgepayments.com`

1. **In Mintlify Dashboard:**
   - Go to Project Settings → Domains
   - Add custom domain: `docs.hedgepayments.com`

2. **Update DNS at your registrar:**
   ```
   Type: CNAME
   Name: docs
   Value: cname.mintlify.com
   ```

3. **Wait for DNS propagation** (~5-60 minutes)
