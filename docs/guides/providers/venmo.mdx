# Venmo Integration Guide

Enable Venmo as a payment method to accept peer-to-peer payments from millions of users in the United States.

## Overview

Venmo integration enables:
- **P2P Payments**: Accept payments from Venmo users
- **Instant Transfers**: Real-time payment processing
- **Social Features**: Leverage Venmo's social payment experience
- **Mobile-First**: Optimized for mobile commerce
- **Wide Reach**: Access to Venmo's large user base
